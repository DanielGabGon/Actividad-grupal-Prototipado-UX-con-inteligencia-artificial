# User Story 1 --- Rutina guiada para principiantes

**Persona:** Andrea Martínez --- Principiante
**Necesidad detectada:** Orientación durante el entrenamiento.

## Historia de usuario

> **Como usuaria principiante, quiero seguir una rutina de entrenamiento
> guiada con instrucciones claras de cada ejercicio, para entrenar
> correctamente sin necesitar conocimientos previos.**

## Criterios de aceptación

1.  La usuaria puede seleccionar una rutina adecuada para nivel
    principiante.
2.  La rutina muestra los ejercicios en el orden en que deben
    realizarse.
3.  Cada ejercicio muestra su nombre, número de series, repeticiones o
    duración y tiempo de descanso.
4.  La usuaria puede consultar una explicación visual o textual sobre
    cómo realizar cada ejercicio.
5.  La usuaria puede marcar cada ejercicio como completado.
6.  La aplicación muestra claramente cuándo se ha completado toda la
    rutina.
7.  **UAT:** una persona sin experiencia previa debe poder iniciar y
    completar una rutina siguiendo las indicaciones de la aplicación sin
    necesitar instrucciones externas.

## Definición de "listo"

La historia se considera terminada cuando una usuaria principiante puede
seleccionar, iniciar, seguir y finalizar una rutina guiada, entendiendo
qué ejercicio debe realizar en cada momento.
