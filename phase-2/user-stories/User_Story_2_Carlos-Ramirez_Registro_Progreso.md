# User Story 2 --- Registro y seguimiento del progreso

**Persona:** Carlos Ramírez --- Intermedio
**Necesidad detectada:** Seguimiento preciso y rápido de su entrenamiento.

## Historia de usuario

> **Como usuario con experiencia intermedia, quiero registrar las
> series, repeticiones y peso utilizado en cada ejercicio, para
> consultar mi historial y evaluar mi progreso en los entrenamientos.**

## Criterios de aceptación

1.  El usuario puede registrar el peso, las repeticiones y las series
    realizadas para cada ejercicio.
2.  El usuario puede consultar los datos registrados durante
    entrenamientos anteriores.
3.  Al realizar nuevamente un ejercicio, puede visualizar los datos de
    su sesión anterior como referencia.
4.  El usuario puede modificar un registro antes de finalizar el
    entrenamiento.
5.  Al finalizar la sesión, los datos registrados quedan disponibles en
    su historial.
6.  La aplicación permite visualizar la evolución de al menos una
    métrica de entrenamiento, como peso, repeticiones o volumen.
7.  **UAT:** un usuario debe poder registrar una serie y consultar su
    registro anterior sin abandonar el flujo principal del
    entrenamiento.

## Definición de "listo"

La historia se considera terminada cuando el usuario puede registrar los
datos principales de sus ejercicios y posteriormente consultarlos para
comparar su progreso.
